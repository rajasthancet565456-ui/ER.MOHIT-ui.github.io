# MR Study PWA

This is a free, static Progressive Web App version of the MR Study landing and planning experience. It has no paid services, no server, and no account requirement.

## Publish free with GitHub Pages

1. Create a repository (for example, `MR-STUDY-PWA`) and upload the contents of this folder to its root.
2. In GitHub, open **Settings → Pages** and deploy from the `main` branch / root folder.
3. Open the Pages URL once while online. In Chrome/Edge mobile, select **Install app** or **Add to Home Screen**. The shell and planner will then work offline.

The manifest and service worker use relative paths, so the app works whether it is hosted at a domain root or inside a GitHub Pages project path.
